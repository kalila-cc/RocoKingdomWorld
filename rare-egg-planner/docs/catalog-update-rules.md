## 来源和分类

1. 先对比远端版本、赛季范围和修订时间，再生成候选清单。记录页面、修订 ID 与同步时间；不能用下载时间替代源数据版本。
2. “本赛季新精灵”不等于“本赛季新异色”。使用 `has_shiny`、异色素材和异色归属元数据交叉核对；精灵上线日期不作为异色赛季依据。
3. 区分赛季限时、常驻、战令来源和其他特殊获取。战令须有通行证奖励/异色蛋来源证据，不能仅由无蛋组推出战令；不能把有野外分布误判为异色常驻。
4. 只收录普通进化链最终形态卡片；分支进化逐条处理，首领形态保留为链路资料，不额外冒充普通最终形态。
5. 同名地区形态按基础 ID 独立；保留现有 `key`、`legacyKey`、`baseId`，不得靠数组顺序迁移拥有记录。
6. 繁育资格、性别限制、后代形态遗传是三项独立规则。用户于 2026-09-19 确认新增默认无性别限制、后代继承当前形态；已有明确限制和磨损形态后代映射保留。出现新的明确证据或用户提供例外时再修正，不把缺少性别比例字段解释为不可繁育。
7. 系别标识使用现有本地素材，不重复下载。新增精灵头像校验 MIME/文件签名和可解码性，不把错误页保存为图片。

## 安装与验收

- 先生成差异报告：新增/缺失卡片、赛季与类型变化、形态拆分、性别和繁育变化；未知分类必须阻止安装，不能自动填限时或常驻。
- 安装前校验卡片键唯一、旧键不丢失、基础 ID 不漂移、后代键和目标引用有效。新增数不能抵消旧卡片被误删的问题。
- 所有资料和图片成功后才原子安装并保留备份；回滚必须覆盖在线源数据和离线数据。绝不读取、改写或提交用户私有进度文件来更新公共图鉴。
- 新旧数据源混用必须有字段级来源证据；旧规划接口不能覆盖已安装的新版卡片。
- 回归测试覆盖赛季筛选、战令排除、常驻优先级、地区形态、仅雌/仅雄、不可繁育和登记键兼容。数量断言随已核实清单更新，不删断言来迁就错误数据。
- 同步在线/离线生成物，不默认提交、推送、打 ZIP 或关机。
- Windows PowerShell 5.1 不能直接点载无 BOM 的中文 UTF-8 源码：生成脚本保留 BOM，模块测试以显式 UTF-8 读取。测试设置 `$ErrorActionPreference = 'Stop'`，防止解析失败/函数不存在仍返回成功的假阳性。

## 本轮避免的错误与后续维护

- 图鉴展示编号（例如月亮砣的 238）、Wiki `pet_*` ID、游戏 `game_id` 与本地自增 `id` 不可互换；既有登记 key/id/baseId 不重新排序编号。
- 头像必须使用页面明确提供的对应关系：月亮砣、测风蝉等的头像文件编号不等于游戏编号，不根据 `game_id` 猜 URL。
- 从模块文本提取字段时，同一记录包含生态蛋的嵌套 `name`；不能用首个 name 匹配当作精灵名。永久自动适配应使用受限 Lua 解析器，本轮精简快照已按页面最终形态名称和编号交叉核对。
- 本轮来源为公开页面快照，记录核验日期，不伪造修订 ID；安装时间只表示本地生成时间，不替代 Wiki 版本。
- `scripts/s4-catalog.json` 保存本轮必要字段和来源，`import-s4-catalog.mjs` 默认只读校验，显式安装时先下载并解码全部头像再更新数据，备份保存在终端打印的临时目录。不修改私有进度。
- 联网旧更新器仍待迁移；防回退校验需同时拦截缺失卡片、编号漂移、赛季变化和获取分类回退。不得以旧更新器可运行冒充支持新版赛季。
