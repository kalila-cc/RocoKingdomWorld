珍稀孵蛋规划台（离线版）

图鉴版本：2026-09-19，已收录 S1–S4 共 78 张最终形态卡片。
S4 新增 19 张（17 张赛季异色、2 张战令异色）；常驻仅雅丹鬃。
旧联网更新器尚未适配新版 Wiki，发现清单缺失或分类回退会拒绝覆盖当前数据库。

打开方式
1. 双击“open-planner.bat”；
2. 或直接双击 index.html。

使用方法
- 状态筛选新增“喜爱”，可集中查看已点亮爱心的图鉴，并与搜索、赛季、性别、蛋组、系别及排除战令组合筛选。
- 图鉴卡片的爱心可标记偏爱：即使已收集，也优先尝试它的异色炫彩。目标赛季内仍有可孵但未收集的异色时，每种偏爱目标最多安排一个母本，余位兼顾异色补全；这些异色收集完成后可重复安排偏爱母本。
- 战令精灵不能生蛋：点亮爱心也不会作为父本、母本或孵化目标。偏爱仍遵守赛季、蛋组、性别、特征及后代形态约束，不保证必出；暂无可行组合时回退常规推荐。
- 爱心独立于拥有登记，会随进度自动保存和导入/导出。进度格式为版本 6；导入旧版文件默认为无偏爱。“清空登记”保留爱心，可再次点击取消。
- 在“异色 · 炫彩图鉴”中，分别登记异色、炫彩、异色炫彩个体的性别；
- 图鉴只登记会影响孵蛋规划的最终目标形态；初始、中间与首领等附加形态不占卡片，可将鼠标悬停或键盘聚焦名称后的圆形 i 查看进化链；
- 同一种最终精灵若有多个地区形态，会按基础 ID 拆成不同卡片，异色、炫彩和异色炫彩均分别登记；
- 三类记录互不覆盖，同一只精灵可同时登记单独异色、单独炫彩和异色炫彩个体；
- 异色炫彩个体会同时计入异色与炫彩拥有进度；
- 顶部“首页、图鉴登记、摆窝推荐”页签会把不同功能分开显示；首次打开显示首页，后续会默认进入更常用的摆窝推荐；
- 图鉴支持按赛季、已登记性别、拥有状态、蛋组和系别筛选，也可搜索精灵名称、地区形态、系别或蛋组；
- 双蛋组和双系别精灵可由任一标签筛中，系别图标已经包含在本地文件中，无需联网加载；
- 页面会自动保存到当前浏览器的本机存储；
- 小窝总数默认为 10，可按实际解锁数量调整；
- 无偏爱目标或偏爱暂不可行时，系统优先推进异色图鉴；常驻目标不会挤掉可行动的赛季限时异色，但可以利用原本空置的窝位；
- 常驻异色雅丹鬃会在限时目标完整覆盖后低优补位；剩余窝位会重复放置相容母本，提高重点目标的蛋产出速度；
- 图鉴页可开启“排除战令精灵”，开启后战令精灵不会计入统计、摆窝推荐与扩散路线，选择会自动保存；
- 在新增异色数量相同时，优先推荐异色炫彩目标，再比较目标种类、有效母本数量与连线质量；
- 在全部窝位有效连接的前提下，先比较可孵的偏爱目标覆盖，再让父母本接近 1:1，随后比较常规目标覆盖、有效母本数量与连线；偏爱覆盖相同时，有效的 5＋5 优先于覆盖更多常规目标的 3＋7。一个父本仍可连接多个母本。父本不足时允许一对多，不虚构未登记父本。均衡度参与推荐度，但不是实际产蛋率预测。
- 已登记的炫彩或异色炫彩母本如果能够在不降低目标覆盖的前提下增加双特征机会，会优先于普通母本并按实际形态显示；
- 摆窝图采用最多四列的多行砖墙式排布，相邻行可错开半格；父本会被优化到能连接更多母本的位置；
- 摆窝页会列出多组可选方案，可通过横向按钮直接切换，并保留完整网格画布便于对照窝位；
- 可将当前摆窝方案导出为 1600 × 1000 PNG 图片，图片包含推荐度、赛季、父母本、珍稀形态角标、连接关系和本轮目标；
- 推荐器会先过滤当前目标下真正有效的父本；有效父本不超过 5 个时精确搜索全部父本子集、母本兼容类型和等价摆位，超过 5 个时自动切换启发式搜索，避免页面长时间无响应；
- 精确方案和摆位结构会在当前会话中缓存；首个方案优先保证整体质量，后续按钮继续提供不同的高质量组合；
- 已登记精灵使用高对比边框、底色与标签，未登记精灵会降低饱和度；
- 推荐图会按父母双方提供的特征组合生成路线：异色父本可搭配目标炫彩母本，反向亦可；
- 旧版异色登记会自动迁移，不会被炫彩登记覆盖；
- 浅色虚线表示同蛋组且小窝横向、纵向或斜角紧邻；当前以九宫格中心窝到角位窝作为最远有效范围；
- 需要换电脑或更换浏览器时，请使用“导出进度”和“导入进度”；导出时会优先打开系统“另存为”窗口，并记住上次使用的目录。
- 离线进度可能与浏览器及当前文件路径关联；移动工具目录、清理浏览器数据或重装系统前，请先导出 JSON 备份。

规则说明
- 后代蛋种跟随母本；
- 亲代异色或炫彩会提高对应珍稀蛋的产出机会，但不是必出；
- 雪影娃娃按当前资料仅有母性；
- 标记为“不可繁育”的目标需要通过其他游戏渠道获得。

数据来源

- BWiki 蛋组计算器
- 炫彩总览

主动更新精灵数据库
1. 确保电脑已连接互联网，并关闭正在打开的离线网页；
2. 双击“update-database.bat”；
3. 更新器会先检查远端数据，显示当前与最新版本；输入 Y 后才会安装；
4. 新数据库、蛋组关系、系别资料和精灵头像全部校验成功后，旧数据库才会被替换；
5. 旧数据会保存在 backup 文件夹，更新失败时不会破坏当前版本；
6. 更新不会清空已有登记；普通卡片继续按名称匹配，地区形态使用独立卡片键；旧名称记录会迁移到更新前所对应的形态，其余新增形态默认为未拥有。

旧更新器依赖旧版 BWiki 语义查询及公开蛋组接口，尚未适配新版 /nrc/ 的数据模块。当前 S4 由人工核验的公开页面快照生成：只把雅丹鬃归为常驻，战令单独分类，其余为赛季异色。不要根据无蛋组标记推断未来战令，也不要把旧接口请求成功当作资料已更新。远端缺少已有卡片、改变基础 ID、赛季或获取类型，以及素材校验失败时，更新器会停止安装并保留当前数据库。

系别图标是工具自带的静态界面资源，不属于精灵数据库。运行更新器只会更新精灵的系别数据，不会联网下载或替换现有系别图标。
