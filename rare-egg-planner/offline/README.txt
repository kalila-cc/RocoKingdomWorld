珍稀孵蛋规划台（离线版）

打开方式
1. 双击“open-planner.bat”；
2. 或直接双击 index.html。

使用方法
- 在“异色 · 炫彩图鉴”中，分别登记异色、炫彩、异色炫彩个体的性别；
- 图鉴只登记会影响孵蛋规划的最终目标形态；初始、中间与首领等附加形态不占卡片，可将鼠标悬停或键盘聚焦名称后的圆形 i 查看进化链；
- 同一种最终精灵若有多个地区形态，会按基础 ID 拆成不同卡片，异色、炫彩和异色炫彩均分别登记；
- 三类记录互不覆盖，同一只精灵可同时登记单独异色、单独炫彩和异色炫彩个体；
- 异色炫彩个体会同时计入异色与炫彩拥有进度；
- 顶部“首页、图鉴登记、摆窝推荐”页签会把不同功能分开显示；首次打开显示首页，后续会默认进入更常用的摆窝推荐；
- 图鉴支持按赛季、已登记性别、拥有状态、蛋组和系别筛选，也可搜索精灵名称、地区形态、系别或蛋组；
- 双蛋组和双系别精灵可由任一标签筛中，系别图标已经包含在本地文件中，无需联网加载；
- 页面会自动保存到当前浏览器的本机存储；
- 小窝总数默认为 10，可按实际解锁数量调整；
- 无需选择目标蛋，系统最高优先推进异色图鉴；尚有可推进的赛季限时异色时，不会用常驻异色占用推荐窝位；
- 雅丹鬃与各赛季战令精灵按常驻不限时异色处理，只有限时目标已集齐，或现有亲本暂时无法推进限时目标时，才会低优补位；
- 图鉴页可开启“排除战令精灵”，开启后战令精灵不会计入统计、摆窝推荐与扩散路线，选择会自动保存；
- 在新增异色数量相同时，优先推荐异色炫彩目标，再比较有效母本覆盖与连线质量；
- 已登记的炫彩或异色炫彩母本如果能够在不降低目标覆盖的前提下增加双特征机会，会优先于普通母本并按实际形态显示；
- 摆窝图采用最多四列的多行砖墙式排布，相邻行可错开半格；父本会被优化到能连接更多母本的位置；
- 摆窝页会列出多组可选方案，可通过横向按钮直接切换，并保留完整网格画布便于对照窝位；
- 已登记精灵使用高对比边框、底色与标签，未登记精灵会降低饱和度；
- 推荐图会按父母双方提供的特征组合生成路线：异色父本可搭配目标炫彩母本，反向亦可；
- 旧版异色登记会自动迁移，不会被炫彩登记覆盖；
- 金色连线表示同蛋组且小窝横向、纵向或斜角紧邻；当前以九宫格中心窝到角位窝作为最远有效范围；
- 需要换电脑或更换浏览器时，请使用“导出进度”和“导入进度”。
- 离线进度可能与浏览器及当前文件路径关联；移动工具目录、清理浏览器数据或重装系统前，请先导出 JSON 备份。

规则说明
- 后代蛋种跟随母本；
- 亲代异色或炫彩会提高对应珍稀蛋的产出机会，但不是必出；
- 雪影娃娃按当前资料仅有母性；
- 标记为“不可繁育”的目标需要通过其他游戏渠道获得。

数据来源
- 洛克王国：世界 BWiki（内置数据库当前覆盖至 S3·铅字幻梦，实际更新时间以页面数据说明为准）
- BWiki 蛋组计算器
- 炫彩总览
- 洛克王国：世界小窝排布计算器

主动更新精灵数据库
1. 确保电脑已连接互联网，并关闭正在打开的离线网页；
2. 双击“update-database.bat”；
3. 更新器会先检查远端数据，显示当前与最新版本；输入 Y 后才会安装；
4. 新数据库、蛋组关系、系别资料和精灵头像全部校验成功后，旧数据库才会被替换；
5. 旧数据会保存在 backup 文件夹，更新失败时不会破坏当前版本；
6. 更新不会清空已有登记；普通卡片继续按名称匹配，地区形态使用独立卡片键；旧名称记录会迁移到更新前所对应的形态，其余新增形态默认为未拥有。

更新器会从洛克王国：世界 BWiki 的语义查询接口读取完整异色形态清单，再按进化系归一为最终孵蛋目标；蛋组、系别、地区形态、进化链和头像由公开蛋组目录与 BWiki 属性资料补齐。同名最终形态会按 variant_label 与基础 ID 自动拆卡，BWiki 中的初始、中间与首领形态只作为附加信息展示。更新时会继续把雅丹鬃列为常驻，并根据“战令目标不可繁育且无蛋组”的远端标记自动识别后续赛季战令精灵；其余赛季异色进入限时优先队列。任一接口结构发生变化或素材校验失败时，更新器会停止安装并保留旧数据库。

系别图标是工具自带的静态界面资源，不属于精灵数据库。运行更新器只会更新精灵的系别数据，不会联网下载或替换现有系别图标。
