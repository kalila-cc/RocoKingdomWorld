## 这是什么

珍稀孵蛋规划台是一款**离线优先、无需账号、数据保存在本机**的《洛克王国：世界》孵蛋辅助工具。它通过“首页、图鉴登记、摆窝推荐”三个顶部页签组织异色图鉴、炫彩登记、蛋组与系别查询、亲本性别和小窝摆放推荐，帮助玩家根据自己已经拥有的精灵，尽可能高效地推进尚未收集的珍稀形态。

如果你正在寻找以下工具，这个项目就是为这些场景准备的：

- 洛克王国世界孵蛋工具、异色孵蛋规划器或炫彩孵蛋助手；
- 洛克王国世界蛋组查询、精灵图鉴或地区形态查询；
- 父本、母本和异色炫彩亲本登记工具；
- 小窝摆放、小窝布局、同蛋组配对或孵蛋路线推荐；
- 可离线打开、无需安装客户端、能够本地保存进度的网页工具。

## 核心功能

### 异色、炫彩与性别登记

- 分别登记每只精灵的**异色、炫彩、异色炫彩**状态；
- 每种珍稀形态均可独立记录雄性与雌性；
- 异色和炫彩可以共存，“异色炫彩”会同时计入两类收集进度；
- 已拥有与未拥有卡片采用明显不同的视觉状态；
- 同名的不同地区形态使用独立图鉴卡片，不会互相覆盖；
- 悬浮信息可查看所在蛋组、进化链、地区形态、异色时效和实际繁育后代。

### 偏爱精灵（爱心）

- 每张图鉴卡片均可点亮爱心，独立于拥有登记；即使已收集，也优先尝试该精灵的异色炫彩。
- 图鉴状态栏提供“喜爱”筛选，只显示点亮爱心的卡片，可与搜索、赛季、性别、蛋组、系别及排除战令组合使用。
- 当前赛季范围内仍有可孵但未收集的异色时，每种偏爱目标至多安排一个母本，其他母本位置兼顾异色补全；这些异色收集完成后，允许重复安排偏爱母本。
- 偏爱不绕过赛季、排除战令、蛋组、性别、珍稀特征和后代形态约束。战令精灵无论是否点亮爱心，均不得作为亲本或孵化目标。
- 没有可行的偏爱异色炫彩组合时回退到常规推荐，并在页面提示；这是增加孵蛋机会，不是必出或概率保证。
- 多个可行偏爱目标先比较覆盖种类，再保留父母本接近 1:1 的效率偏好；一个父本仍可连接多个母本。
- 爱心自动保存并随 JSON 进度导入/导出（版本 6）；旧进度无爱心字段时默认为无偏爱。同名不同形态按独立卡片键保存。“清空登记”保留爱心，可单独点击取消。

### 自动生成小窝摆放方案（布局）

- 根据用户已登记的珍稀父本和目标母本自动寻找同蛋组组合；
- 默认支持 10 个小窝，并生成多行、多列的紧邻排布；
- 横向、纵向以及紧挨父本的斜角小窝均可建立有效配对；
- 用浅色虚线直观展示哪些父本可以覆盖哪些母本，同时降低连线对头像和名称的视觉干扰；
- 同时展示当前方案推荐度、本轮蛋单和后续珍稀形态扩散路线；
- 支持切换赛季范围，并通过一排方案按钮直接比较和切换多组可行摆法；在全部窝位有效连接的前提下，先比较可孵的偏爱目标覆盖，再按父母本接近 1:1 排序，随后比较限时目标覆盖、目标种类和有效母本数量；
- 当前摆窝方案可导出为 1600 × 1000 PNG 图片，保留赛季、推荐度、父母本、珍稀形态角标、连接关系和本轮目标，方便在手机查看或分享。

### 精确与启发式混合搜索

- 推荐器会先按当前赛季、目标形态、蛋组和可用母本过滤出真正能够推进进度的有效父本；
- 有效父本候选不超过 5 个时，首选方案会完整搜索父本子集，并用兼容位图动态规划精确分配母本与窝位；
- 精确搜索依次比较全部窝位是否使用、父母本是否实际接入、偏爱异色炫彩目标覆盖、父母本比例、限时目标覆盖、目标种类和有效母本数量；不会用“母本更多”提前剪掉比例更好的候选；
- 兼容能力相同的母本会先按父本兼容位图聚合，再在组内按形态收益和后续扩散能力挑选具体目标，避免重复枚举等价组合；
- 不同目标不足以填满小窝时，会重复放置相容母本来提高对应蛋的产出速度；例外是尚有未收集异色时，偏爱目标每种母本至多一个，不能为填满窝位而突破此限制；
- 有效父本超过 5 个时自动切换到启发式搜索，避免组合数量增长造成页面长时间无响应；
- 摆位结构和精确方案会在当前会话中缓存；第一套方案优先保证全局质量，其余按钮继续提供不同的高质量可选组合。

### 面向收集进度的推荐优先级

推荐器不会要求玩家逐个选择目标蛋，而是根据当前图鉴自动排序：

1. 有可行偏爱目标时优先尝试其异色炫彩，并按上述规则兼顾异色补全；无偏爱或偏爱暂不可行时，优先推进当前亲本能够覆盖的**赛季限时未拥有异色**；
2. 在不挤掉限时目标的前提下，原本空置的窝位可以低优补充**常驻不限时异色**；剩余位置再重复放置限时母本；
3. 在能够新增相同数量异色的方案之间，优先保留可形成**异色炫彩**的双特征机会；
4. 已登记的炫彩或异色炫彩母本如果能够在不降低有效覆盖的前提下推进目标，会优先于普通母本进入方案；
5. 暂时没有可行动的异色路线时，推荐器才回退到单独的**炫彩扩散**；
6. 常驻异色雅丹鬃可以利用限时方案的剩余窝位，但不会替换可行动的限时目标；不可繁育的战令精灵仍可由玩家整体排除。

### 区分“可以繁育”与“形态可以遗传”

蛋组信息只能说明两只精灵能否作为亲本配对，并不代表母本当前外观一定能够由蛋继承。工具为此单独维护“繁育后代形态”：

- 磨损形态仍然可以登记，也可以作为亲本参与繁育；
- 因为磨损是后天形成的状态，孵化结果会回到“本来的样子”；
- 推荐器不会错误地把磨损形态列成能够直接孵出的目标蛋；
- 其他无法通过孵蛋原样获得的卡片会计入“需其他渠道”。

### 图鉴与蛋组筛选

- 支持按精灵名称、地区形态、系别和蛋组搜索；
- 支持按赛季、已登记性别、已拥有和未拥有状态筛选；
- 提供蛋组与系别快捷索引，双蛋组和双系别精灵可由任一标签筛中；
- 系别使用随工具内置的本地图标，不依赖网络加载；
- 可一键排除战令精灵；
- 排除战令后，战令精灵不会计入图鉴统计、摆窝推荐和扩散路线，筛选偏好会随本地进度保存；
- 提供当前全部蛋组的快捷索引和数量统计；
- 图鉴按最终形态登记，初始形态、进化过程和首领等附加形态通过信息提示展示；
- 赛季限时与常驻异色拥有不同标签，方便快速判断收集顺序。

### 离线运行与本地持久化

- 完整页面、精灵数据、图片和推荐算法均包含在 `offline/` 中；
- 打开后不需要联网，也不需要启动本地服务器；
- 登记进度使用浏览器本地存储，不会上传用户数据；
- 支持通过系统“另存为”窗口导出 JSON 进度文件，并可重新导入以备份或迁移设备；支持的浏览器会记住上次使用的保存目录；
- 摆窝推荐支持导出独立 PNG 方案图；支持的浏览器会打开系统“另存为”窗口，不支持时自动使用普通下载；
- 附带数据库更新器，用户可以主动获取最新异色清单、蛋组、系别资料和精灵头像素材；
- 系别图标是经过压缩的静态界面资源，不属于精灵数据库，更新器不会重新下载或替换；
- 更新前会检查远端结构，安装时自动备份旧数据库，失败时不会覆盖现有数据。

## 推荐逻辑概览

在窝位占满、全部亲本有效连接的前提下，先比较可孵的偏爱异色炫彩目标覆盖，再选择父本与母本数量接近 1:1 的方案，随后比较常规目标覆盖、目标种类、有效母本数量与连线。偏爱覆盖相同时，有效的 5 父本＋5 母本优先于覆盖更多常规目标的 3 父本＋7 母本。比例按参与配对的窝位个体计算，不按连线数量计算；一个父本仍可以连接多个母本。父本不足时允许一对多，不虚构未登记父本。当前范围内尚有可孵但未收集的异色时，每种偏爱母本至多一个，不为填满窝位而突破此限制。推荐度包含父母本均衡度，不包含窝位利用率。该评分是排序偏好，不是实际产蛋率的数值预测。

```text
已有珍稀父本与已登记珍稀母本
      ↓
匹配同蛋组、性别和可繁育规则
      ↓
排除无法作为孵化结果遗传的地区形态
      ↓
优先尝试偏爱异色炫彩；尚有未收集异色时每种偏爱母本至多一个
      ↓
兼顾异色补全；偏爱不可行时使用常规限时、常驻收集优先级
      ↓
同等异色覆盖下优先异色炫彩机会
      ↓
异色暂不可推进时回退到炫彩扩散
      ↓
在 10 个小窝内优化父本覆盖、重复母本产能和双特征收益
      ↓
有效父本 ≤ 5 时精确搜索，否则启发式搜索
      ↓
生成可视化摆放方案、蛋单与后续扩散路线
```

当前的小窝距离口径采用九宫格中心到角位的范围：父本与母本横向、纵向或斜角紧邻时视为有效。公开资料尚未证明父本与某一母本配对后存在阻止其覆盖其他母本的独立冷却，因此规划器允许一个父本同时覆盖多个相邻的同蛋组母本。

## 常见问题

### 为什么不需要手动选择目标蛋？

默认根据登记进度优先推进赛季限时异色，并用剩余位置补常驻目标或重复相容母本。也可以点亮图鉴爱心，优先尝试喜爱精灵的异色炫彩，即使已经收集。当前范围内还有可孵但未收集的异色时，每种偏爱母本至多一个，其余位置兼顾异色补全；收集完成后可重复安排偏爱母本。偏爱暂无可行组合时回退到常规推荐。玩家仍可通过赛季筛选缩小规划范围，战令精灵始终不参与繁育。

### 异色和炫彩可以同时登记吗？

可以。异色、炫彩和异色炫彩是三个互不覆盖的登记项；异色炫彩会同时影响异色与炫彩的收集统计和推荐能力。

### 为什么磨损形态没有出现在推荐蛋单中？

磨损形态是后天形成的外观，亲本仍可繁育，但蛋只能孵出非磨损形态。图鉴会保留独立登记卡片，推荐器则显示其实际后代为原形态。

### 为什么登记了炫彩母本，摆窝里仍然可能都是普通母本？

后代蛋种跟随母本。为了把珍稀特征扩散给尚未拥有的目标，推荐器通常会使用目标精灵的普通母本与珍稀父本配对。已经拥有炫彩的母本只有在它还能推进缺失异色、形成异色炫彩机会，或在不降低有效覆盖的前提下优于普通候选时才会入选；入选后会明确显示为“炫彩母本”或“异色炫彩母本”。

### 离线页面会上传我的图鉴吗？

不会。登记数据默认只保存在当前浏览器的本地存储中。除非用户主动运行数据库更新器，否则工具不需要访问网络。

离线进度还可能与浏览器及文件打开路径关联。移动工具目录、更换浏览器、清理网站数据或重装系统前，建议先使用“导出进度”，在系统“另存为”窗口中自主选择位置保存 JSON 备份，再在新环境中导入。浏览器不支持系统文件选择器时，会自动退回普通下载。

### 数据库更新失败会丢失记录吗？

不会。更新器会先下载到临时目录并校验文件，再备份旧数据库；失败时会恢复旧数据。建议同时定期使用页面内的“导出进度”功能保存个人登记。

## 项目结构

```text
rare-egg-planner/
├─ app/                    # React 页面、组件、持久化 Hook 和推荐领域引擎
├─ styles/site/            # 在线与离线共用的 CSS 源码
├─ public/                 # 网页使用的精灵与珍稀形态素材
├─ offline/                # 无需服务器、可直接打开的完整离线版本
├─ scripts/updater/        # 数据库更新器的分模块源码
├─ scripts/                # 离线资源生成和打包脚本
└─ tests/                  # 服务端渲染、数据与推荐规则回归测试
```

推荐算法只维护在 `app/planner-core.ts`，构建时自动生成离线浏览器版本。样式只维护在 `styles/site/`，在线和离线 CSS 由同一组分片生成。更新器只维护 `scripts/updater/`，项目脚本和离线单文件更新器由构建过程同步生成。
