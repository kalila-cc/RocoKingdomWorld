## 这是什么

珍稀孵蛋规划台是一款**离线优先、无需账号、数据保存在本机**的《洛克王国：世界》孵蛋辅助工具。它将异色图鉴、炫彩登记、蛋组查询、亲本性别和小窝摆放推荐集中在同一个页面中，帮助玩家根据自己已经拥有的精灵，尽可能高效地推进尚未收集的珍稀形态。

如果你正在寻找以下工具，这个项目就是为这些场景准备的：

- 洛克王国世界孵蛋工具、异色孵蛋规划器或炫彩孵蛋助手；
- 洛克王国世界蛋组查询、精灵图鉴或地区形态查询；
- 公体、母体和异色炫彩亲本登记工具；
- 小窝摆放、小窝布局、同蛋组配对或孵蛋路线推荐；
- 可离线打开、无需安装客户端、能够本地保存进度的网页工具。

## 核心功能

### 异色、炫彩与性别登记

- 分别登记每只精灵的**异色、炫彩、异色炫彩**状态；
- 每种珍稀形态均可独立记录雄性与雌性；
- 异色和炫彩可以共存，“异色炫彩”会同时计入两类收集进度；
- 已拥有与未拥有卡片采用明显不同的视觉状态；
- 同名的不同地区形态使用独立图鉴卡片，不会互相覆盖；
- 悬浮信息可查看所在蛋组、进化链、地区形态、异色时效和实际繁育后代。

### 自动生成小窝摆放方案

- 根据用户已登记的珍稀公体和目标母体自动寻找同蛋组组合；
- 默认支持 10 个小窝，并生成多行、多列的紧邻排布；
- 横向、纵向以及紧挨父本的斜角小窝均可建立有效配对；
- 用连线直观展示哪些父本可以覆盖哪些母本；
- 同时展示有效配对数、可覆盖目标数、未覆盖路线和方案推荐度；
- 支持切换赛季范围以及重新生成另一组可行方案。

### 面向收集进度的推荐优先级

推荐器不会要求玩家逐个选择目标蛋，而是根据当前图鉴自动排序：

1. 优先寻找能够产出**异色炫彩**的组合；
2. 其次推进尚未拥有的**异色**；
3. 最后补充**炫彩**路线；
4. 可行动的赛季限时异色优先于常驻不限时异色；
5. 雅丹鬃和各赛季战令精灵等常驻触发异色仅在限时目标无法继续推进时补位。

### 区分“可以繁育”与“形态可以遗传”

蛋组信息只能说明两只精灵能否作为亲本配对，并不代表母体当前外观一定能够由蛋继承。工具为此单独维护“繁育后代形态”：

- 磨损形态仍然可以登记，也可以作为亲本参与繁育；
- 因为磨损是后天形成的状态，孵化结果会回到“本来的样子”；
- 推荐器不会错误地把磨损形态列成能够直接孵出的目标蛋；
- 其他无法通过孵蛋原样获得的卡片会计入“需其他渠道”。

### 图鉴与蛋组筛选

- 支持按精灵名称、地区形态和蛋组搜索；
- 支持按赛季、已拥有、未拥有筛选；
- 提供当前全部蛋组的快捷索引和数量统计；
- 图鉴按最终形态登记，初始形态、进化过程和首领等附加形态通过信息提示展示；
- 赛季限时与常驻异色拥有不同标签，方便快速判断收集顺序。

### 离线运行与本地持久化

- 完整页面、精灵数据、图片和推荐算法均包含在 `offline/` 中；
- 打开后不需要联网，也不需要启动本地服务器；
- 登记进度使用浏览器本地存储，不会上传用户数据；
- 支持导出和导入 JSON 进度文件，方便备份或迁移设备；
- 附带数据库更新器，用户可以主动获取最新异色清单、蛋组资料和精灵素材；
- 更新前会检查远端结构，安装时自动备份旧数据库，失败时不会覆盖现有数据。

## 快速开始

### 直接使用离线版

1. 下载或克隆本仓库；
2. 进入 [`offline/`](./offline/) 目录；
3. Windows 用户双击 `open-planner.bat`；
4. 也可以直接使用浏览器打开 `offline/index.html`。

```bash
git clone git@github.com:kalila-cc/RocoKingdomWorld.git
cd RocoKingdomWorld/rare-egg-planner/offline
```

macOS 和 Linux 用户可直接打开 `index.html`。离线页面本身不依赖 Node.js、Python 或数据库服务。

### 更新精灵数据库

Windows 用户可以双击：

```text
offline/update-database.bat
```

更新器会读取 BWiki 异色形态资料和公开蛋组接口，先展示当前数据库与远端数据摘要，再由用户确认是否安装。已有登记记录会按精灵卡片键继续保留。

## 推荐逻辑概览

```text
已有珍稀公体
      ↓
匹配同蛋组、性别和可繁育规则
      ↓
排除无法作为孵化结果遗传的地区形态
      ↓
赛季限时异色 > 常驻异色
      ↓
异色炫彩 > 异色 > 炫彩
      ↓
在 10 个小窝内优化父本覆盖和母本数量
      ↓
生成可视化摆放方案、蛋单与后续扩散路线
```

当前的小窝距离口径采用九宫格中心到角位的范围：父本与母本横向、纵向或斜角紧邻时视为有效。公开资料尚未证明公体与某一母体配对后存在阻止其覆盖其他母体的独立冷却，因此规划器允许一个公体同时覆盖多个相邻的同蛋组母体。

## 常见问题

### 为什么不需要手动选择目标蛋？

工具的目标是尽快补齐尚未拥有的异色，因此会读取本地登记进度，自动按限时异色、常驻异色和炫彩路线排序。玩家仍可通过赛季筛选缩小规划范围。

### 异色和炫彩可以同时登记吗？

可以。异色、炫彩和异色炫彩是三个互不覆盖的登记项；异色炫彩会同时影响异色与炫彩的收集统计和推荐能力。

### 为什么磨损形态没有出现在推荐蛋单中？

磨损形态是后天形成的外观，亲本仍可繁育，但蛋只能孵出非磨损形态。图鉴会保留独立登记卡片，推荐器则显示其实际后代为原形态。

### 离线页面会上传我的图鉴吗？

不会。登记数据默认只保存在当前浏览器的本地存储中。除非用户主动运行数据库更新器，否则工具不需要访问网络。

### 数据库更新失败会丢失记录吗？

不会。更新器会先下载到临时目录并校验文件，再备份旧数据库；失败时会恢复旧数据。建议同时定期使用页面内的“导出进度”功能保存个人登记。

## 本地开发

需要 Node.js 22.13 或更高版本。

```bash
npm install

```

常用命令：

```bash
npm run lint             # 代码检查
npm test                 # 构建与回归测试
npm run build            # 构建网页并同步离线共享资源
npm run package:offline  # 生成可分发的离线目录与 ZIP
```

## 项目结构

```text
rare-egg-planner/
├─ app/                    # React 页面、组件、持久化 Hook 和推荐领域引擎
├─ styles/site/            # 在线与离线共用的 CSS 源码
├─ public/                 # 网页使用的精灵与珍稀形态素材
├─ offline/                # 无需服务器、可直接打开的完整离线版本
├─ scripts/updater/        # 数据库更新器的分模块源码
├─ scripts/                # 离线资源生成和打包脚本
└─ tests/                  # 服务端渲染、数据与推荐规则回归测试
```

推荐算法只维护在 `app/planner-core.ts`，构建时自动生成离线浏览器版本。样式只维护在 `styles/site/`，在线和离线 CSS 由同一组分片生成。更新器只维护 `scripts/updater/`，项目脚本和离线单文件更新器由构建过程同步生成。
